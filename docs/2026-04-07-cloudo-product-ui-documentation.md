# Cloudo 产品与界面说明文档

更新时间：2026-04-07

## 1. 文档目的

本文档面向产品经理、UI 设计师、交互设计师与项目协作者，用于说明 Cloudo 当前版本的产品定位、页面结构、功能边界、界面布局、关键交互与设置能力。

本文档刻意不展开技术实现细节，而是从产品视角描述“这个项目现在是什么、用户能做什么、每个页面长什么样、应该如何继续设计与优化”。

## 2. 产品定位

Cloudo 是一款桌面端时间管理与笔记协同工具，目标是把“今天要做什么”“什么时候做”“做的过程中记下什么”整合进一个连续工作流中。

它不是传统意义上的大型项目管理系统，也不是纯文档工具，而是一个偏个人效率场景的轻量桌面工作台。

当前产品核心由两大主能力构成：

- 时间管理：把待办整理成可拖拽、可排期、可复盘的日程看板
- 笔记管理：把笔记放在独立页面中，支持分层目录、所见即所得编辑、目录导航和批注

此外，产品还包含一个桌面快捷浮窗，用于承接“今天任务总览”和“快速勾选完成”的轻量场景。

## 3. 目标用户

当前版本更适合以下人群：

- 个人工作者、独立开发者、内容创作者
- 需要把待办和时间安排放在同一个界面里的人
- 习惯边做边记的人
- 希望在 Windows 桌面上长期驻留一个效率工具的人

## 4. 产品结构总览

当前产品信息架构非常清晰，只有三个一级页面和一个浮窗形态。

### 4.1 一级页面

- 时间管理页
- 笔记页
- 设置页

### 4.2 辅助形态

- 快捷浮窗

### 4.3 导航方式

产品采用桌面应用常见的左侧竖向导航栏。

导航栏从上到下分为三层：

- 品牌区域：顶部品牌云朵图形
- 主导航：时间管理、笔记
- 快捷操作：主题切换、快捷浮窗、快速新建
- 底部入口：设置

这种结构的优点是：

- 主功能与系统功能分层清楚
- 保持桌面工具的“固定位置肌肉记忆”
- 能把“效率动作”放在比设置更高频的位置

## 5. 全局体验特征

### 5.1 产品气质

当前界面气质偏轻量、安静、工具型，整体更接近“高频工作台”而不是“品牌展示型产品”。

### 5.2 视觉倾向

- 以浅色主题为基础
- 使用卡片、面板、分栏和轻量阴影构建层级
- 图标按钮较多，强调桌面工具式高密度操作
- 支持浅色 / 深色 / 跟随系统

### 5.3 交互倾向

- 强调拖拽
- 强调就地编辑
- 强调轻量反馈
- 大量使用面板折叠、局部展开、悬浮按钮和弹层

### 5.4 数据使用方式

产品核心面向本地使用场景，当前版本主要强调本地保存与桌面使用连续性。

## 6. 页面一：时间管理页

时间管理页是整个产品当前最强的主工作台页面，也是信息密度最高的页面。

### 6.1 页面目标

帮助用户完成以下连续动作：

1. 创建待办
2. 给待办分类
3. 把待办拖入某个日期 / 某个时间段
4. 在执行过程中查看详情或完成任务
5. 在右侧轻笔记里记录即时信息

### 6.2 页面总体布局

这是一个“三栏布局”的工作页，中间以可拖拽分隔条控制宽度。

从左到右分别是：

- 左栏：待办池
- 中栏：日程区
- 右栏：轻笔记

页面顶部还包含：

- 页面标题区：“时间管理看板”
- 问候语区：根据时间段显示 greeting 文案
- 视图切换区：日视图 / 周视图 / 月视图

### 6.3 顶部区域

顶部区域较简洁，承担两个作用：

- 传递页面身份：时间管理看板
- 提供视图切换：日、周、月

对设计师来说，这个区域不是复杂控制台，更像是一个轻量头部条，主要用于建立当前上下文，而不是承载大量操作。

### 6.4 左栏：待办池

左栏是任务来源区，所有待办先进入这里，再被安排到时间轴或日期格中。

#### 布局组成

- 标题：待办池
- 统计信息：当前类型名 + 当前类型任务数 / 全部任务数
- 主按钮：`+ 新建任务`
- 类型切换条：上一类型、当前类型、下一类型、管理入口
- 类型管理区域：新增 / 重命名 / 删除 / 关闭
- 任务列表区域

#### 卡片内容

每条待办卡片包含：

- 任务标题
- 所属类型
- 预计时长（分钟）
- 操作按钮

#### 卡片操作

每条待办支持：

- 完成 / 恢复
- 编辑
- 查看详情 / 收起详情
- 删除
- 拖拽到日程区

#### 类型管理能力

当前产品把“类型”设计成时间管理页内部的重要组织方式。

支持：

- 新增类型
- 重命名类型
- 删除类型
- 在类型之间切换查看任务

删除类型时，任务不会直接丢失，而是迁移回基础类型。这种逻辑非常适合个人效率产品，因为用户更在意“任务别丢”，而不是严格的分类完整性。

#### 空状态

当当前类型下没有待办时，会出现空状态提示，并给出“去创建”的按钮。

这意味着左栏既承担数据展示，也承担引导动作。

### 6.5 中栏：日程区

中栏是整个时间管理页的核心，是把任务从“待办”转化为“计划”的地方。

它根据当前视图分为三种形态。

#### 6.5.1 日视图

这是最完整、最强的视图形态。

布局元素包括：

- 区域标题：日程计划
- 日期选择器
- 纵向时间轴，从 0:00 到 24:00
- 时间卡片
- 当前时间线
- 拖拽预览卡片

#### 日视图核心行为

支持以下关键操作：

- 把左栏待办拖到时间轴中形成排期
- 拖动已有日程卡片改变时间位置
- 通过顶部 / 底部拖拽柄调整开始和结束时间
- 打开日程详情
- 从时间轴移除日程
- 标记完成
- 编辑关联待办

#### 日程卡片内容

每张时间卡片上会展示：

- 标题
- 时间段
- 编辑按钮
- 详情按钮
- 删除按钮
- 完成按钮

这使得中栏不是纯展示日历，而是真正的“就地操作日程画布”。

#### 删除反馈

删除日程不是直接消失，而是：

- 先弹出确认层
- 删除后出现撤销条
- 用户可以在短时间内撤销

这是一种相对成熟的桌面效率产品交互。

#### 详情查看

日程详情通过模态层显示，内容包括：

- 标题
- 类型
- 时间段
- 详情文本

对于 UI 来说，这个层级比编辑轻，属于“查看型详情”而非“大表单”。

#### 6.5.2 周视图

周视图是压缩后的计划概览页。

布局特征：

- 一周七天网格
- 每天显示日期按钮
- 每天显示任务数量
- 每天显示少量任务预览
- 支持把某一天展开成更细的纵向时段视图

用户可以在周视图中：

- 快速看哪一天任务多
- 将待办直接拖入某一天
- 展开某一天看更细的时间块
- 点击任务回到日视图继续精排

这说明周视图更偏“分配与巡检”，不是最终精细排期页。

#### 6.5.3 月视图

月视图是更轻量的长期概览。

布局特征：

- 月历格子
- 非本月日期会弱化显示
- 每个日期格仅展示日期与任务数量

用户可以：

- 把待办拖进某一天
- 点击某一天进入日视图

因此月视图的产品角色是“时间入口索引”，而不是完整的月度计划画布。

### 6.6 右栏：轻笔记

右栏是时间管理页中的即时记录区域，属于“边做边记”的快速笔记模式。

#### 结构

- 标题：轻笔记
- 一排轻量工具按钮
- 富文本编辑区域

#### 编辑能力

支持：

- 加粗
- 斜体
- 无序列表
- 插入链接
- 粘贴富文本 / Markdown 内容

#### 交互特点

- 采用 contentEditable 的轻量编辑方式
- 信息密度比正式笔记页低
- 更适合记录临时信息、任务说明、会议中的短记要点

#### 与中栏的关系

轻笔记与时间管理页同屏出现，这让它更像“执行过程中的旁边草稿纸”，而不是独立知识库。

从产品结构上，它承担的是：

- 临时记录
- 快速补充说明
- 与今日计划强关联的轻量文本

### 6.7 弹层与辅助交互

时间管理页当前还包含几个重要弹层：

- 新建 / 编辑待办弹层
- 日程详情弹层
- 删除确认弹层
- 撤销提示条

#### 新建 / 编辑待办弹层字段

- 标题
- 类型
- 时长
- 详情

这是当前产品最主要的任务录入入口。

## 7. 页面二：笔记页

笔记页是产品第二大主功能页面，整体更像一个桌面文档工作区。

### 7.1 页面目标

帮助用户：

- 管理本地笔记文件
- 组织目录结构
- 编辑富文本内容
- 查看文档目录
- 添加评论和批注
- 在本地进行保存、导入、刷新与恢复

### 7.2 页面总体布局

笔记页整体是“顶部信息条 + 三栏编辑区”的结构。

从左到右分别是：

- 左栏：文件树
- 中栏：编辑区
- 右栏：评论与批注

中栏内部又进一步分成：

- 左侧目录栏
- 中间正文编辑 / 预览区
- 右侧评论栏

这意味着它本质上是一个“1.5 层三栏系统”。

### 7.3 顶部信息条

顶部信息条包含：

- 本地目录路径
- 当前文档面包屑
- 保存状态文案
- 字数统计
- 保存到本地按钮
- 全文复制按钮

这个区域更偏“状态条”，不是强操作工具栏。

对设计师来说，这里应该强调：

- 状态可见性
- 当前上下文清晰
- 操作按钮轻量不喧宾夺主

### 7.4 左栏：文件树

左栏是笔记结构管理区。

#### 左栏工具按钮

支持：

- 折叠 / 展开文件树
- 新建文件
- 新建文件夹
- 刷新
- 导入

#### 目录树能力

文件树支持：

- 多层文件夹
- 展开 / 折叠
- 右键菜单操作
- 选择文件夹
- 选择文件

#### 右键菜单能力

针对文件夹：

- 新建文件
- 新建文件夹
- 查看目录
- 剪切
- 复制
- 粘贴
- 重命名
- 删除

针对文件：

- 重命名文件
- 删除文件

#### 文件树角色

它不是简单列表，而是接近桌面文件管理器逻辑。对于产品定位来说，这会让用户感觉自己在管理“真正的本地笔记资产”，而不是管理某个在线系统里的条目。

### 7.5 中栏：编辑工作区

中栏是笔记页最复杂的部分。

它由两部分组成：

- 顶部编辑工具栏
- 下方正文工作区

#### 7.5.1 编辑工具栏

当前工具栏支持：

- 撤销
- 重做
- 块格式切换
- 加粗
- 斜体
- 有序列表
- 链接
- 清除格式
- 更多菜单
- 编辑模式
- 预览模式
- 纯净写作模式

“更多菜单”中还包含：

- 左对齐
- 居中
- 右对齐
- 代码

#### 7.5.2 正文工作区结构

正文工作区内部继续分为三块：

- 目录栏
- 正文画布
- 批注栏

这三块都支持折叠或调宽，因此用户可以在“结构感”和“专注感”之间切换。

#### 7.5.3 编辑模式

编辑模式下，正文区域是所见即所得编辑器。

特点：

- 直接在正文中输入
- 支持粘贴 Markdown 或富文本
- 能通过工具栏调整格式
- 更适合不熟悉纯 Markdown 的普通用户

#### 7.5.4 预览模式

预览模式下，正文以只读文章形式展示。

这个模式主要用于：

- 阅读检查
- 排版确认
- 目录跳转浏览

#### 7.5.5 纯净写作模式

这是笔记页一个非常重要的体验开关。

开启后会收起辅助区域，让用户更专注于正文本身。

它适合：

- 长文写作
- 深度整理笔记
- 只关注内容不关注结构和批注的时候

### 7.6 目录栏

目录栏根据正文中的标题自动生成。

#### 作用

- 显示当前文档的结构层级
- 点击后跳转到对应标题位置
- 在长文档中充当导航器

#### 视觉角色

对设计来说，它应该更像“辅助导航树”，而不是主角，因此信息层级应弱于正文，但强于批注。

### 7.7 正文画布

正文画布是整页的主视觉重心。

当前特征：

- 中央画布式布局
- 富文本风格
- 适合长内容输入
- 支持选择文本进行批注操作

它不是“像网页正文一样无限延展”，而更接近“桌面文档编辑器中心画布”。

### 7.8 评论与批注栏

右侧栏用于承接评论和基于选区的批注。

#### 结构

- 标题：评论与批注
- 计数
- 输入框
- 发布按钮
- 评论列表

#### 支持的行为

- 输入评论
- 回车发布
- 针对选中文本建立批注
- 点击评论后回到正文中的对应位置
- 删除评论

#### 产品意义

这让笔记页不只是“个人记录工具”，还具备一定“审阅”和“内容整理”的意味。

对 PM 而言，这给后续发展留下了空间：

- 个人复盘标记
- 协作批注
- 内容审校

### 7.9 文件操作与本地化能力

当前笔记页已经具备明显的“本地文件产品”特征。

用户可见能力包括：

- 从本地导入 Markdown
- 刷新本地文件内容
- 手动保存到本地
- 显示本地目录路径

因此笔记页在产品认知上更接近“本地知识工作区”，而不是纯云端笔记。

## 8. 页面三：设置页

设置页当前是一个较轻量的系统控制页，主要聚焦应用外观和快捷键。

### 8.1 页面目标

帮助用户对应用外观和调用方式进行基础定制。

### 8.2 页面总体布局

采用卡片网格结构，目前包含三张设置面板：

- 外观
- 快捷键
- 存储

### 8.3 设置卡片一：外观

包含以下项目：

- 主题模式
- 主窗口透明度
- 快捷浮窗透明度

#### 主题模式

提供三种选择：

- 跟随系统
- 浅色
- 夜间

#### 主窗口透明度

用于控制主应用窗口整体视觉透明程度。

#### 快捷浮窗透明度

用于单独控制快捷浮窗透明度，不与主窗口绑定。

这说明产品把浮窗视为一个独立的视觉形态，而不是主窗口的附属面板。

### 8.4 设置卡片二：快捷键

包含以下项目：

- 浮窗显示 / 隐藏快捷键
- 快捷创建待办快捷键
- 保存快捷键按钮
- 恢复默认按钮
- 状态反馈文案
- 主窗口固定快捷键说明

#### 当前默认快捷键

- 主窗口显示 / 隐藏：Alt + Space
- 快捷浮窗：Alt + Q
- 快捷创建待办：Alt + N

#### 使用意义

这使产品非常符合桌面工具的使用习惯，用户不必每次都回到主界面再操作。

### 8.5 设置卡片三：存储

当前存储区域信息较少，主要体现“Markdown 按项目文件夹管理”的产品方向。

从产品角度看，这块未来仍有很大扩展空间，可继续发展为：

- 本地存储目录说明
- 自动保存策略说明
- 导入导出能力说明
- 备份策略
- 多设备同步入口

## 9. 快捷浮窗

快捷浮窗是本产品很有代表性的辅助工作形态。

### 9.1 产品角色

它不是完整页面，而是一个轻量任务卡片窗口，适合以下场景：

- 临时查看今天还要做什么
- 在不开主窗口的情况下快速勾选任务
- 作为桌面常驻的小型执行面板

### 9.2 内容结构

浮窗会展示“今日任务”列表，每项包含：

- 任务标题
- 时间信息
- 完成状态

同时支持：

- 单项完成切换
- 一键完成全部未完成任务

### 9.3 与主窗口关系

浮窗并不是孤立存在，它与主窗口共享今天的任务状态。

因此它在产品结构中的角色更像：

- 主工作台的快捷入口
- 今日执行清单的桌面外显层

## 10. 关键用户流程

### 10.1 时间规划流程

1. 进入时间管理页
2. 在左栏创建待办
3. 给待办选择类型、时长和详情
4. 将待办拖入日视图时间轴或周 / 月视图日期格
5. 在中栏查看与调整日程
6. 在右栏轻笔记中记录即时想法
7. 在执行完成后勾选任务

### 10.2 写作与整理流程

1. 进入笔记页
2. 在左栏新建文件夹 / 文件
3. 在中栏编辑文档
4. 通过目录快速跳转
5. 为选中文本添加评论或批注
6. 保存到本地
7. 需要时从本地文件刷新或导入

### 10.3 桌面快速执行流程

1. 通过快捷键或侧边栏打开快捷浮窗
2. 查看今日任务
3. 快速勾选任务完成
4. 必要时切回主窗口继续细化计划

## 11. 当前功能边界

从产品视角看，当前版本已经形成了明确的 MVP 以上能力，但仍然属于“单机个人效率工具”的成熟早期阶段。

### 11.1 已经比较明确的能力

- 时间管理与笔记是两个稳定主模块
- 三栏桌面布局已经形成产品识别度
- 快捷浮窗让桌面使用场景成立
- 设置页能承接基础个性化
- 笔记已具备明显的本地文件产品方向

### 11.2 当前仍偏轻量的部分

- 设置页信息量较少
- 存储策略对普通用户的说明还不够完整
- 时间管理页的数据分析与复盘视图尚未出现
- 笔记页还没有更完整的全局搜索、标签、历史版本等能力

## 12. 对产品经理的建议

如果继续推进这个项目，建议下一阶段优先围绕以下方向补强。

- 明确“轻笔记”和“正式笔记”的关系
- 设计待办、日程、笔记三者之间的关联模型
- 强化本地存储说明、备份与恢复路径
- 在设置页增加更完整的使用说明与偏好项
- 为时间管理页补充“今日总结 / 本周回顾”层

## 13. 对 UI / 交互设计师的建议

### 13.1 时间管理页

- 强化三栏主次关系，避免左中右三栏权重过于平均
- 日视图是主战场，应进一步突出时间轴与卡片层级
- 周视图和月视图可以再做更明显的“概览感”和“密度差异”

### 13.2 笔记页

- 当前页面信息层级丰富，建议重点打磨“顶部状态条、左树、中画布、右批注”的视觉节奏
- 纯净写作模式可以成为一个更有辨识度的设计亮点
- 评论与批注区可适当增强“关联正文”的感知

### 13.3 设置页

- 现在偏基础表单，可继续向“桌面应用控制中心”方向升级
- 适合加入说明型文案、状态卡、路径提示、策略提示

## 14. 一句话总结

Cloudo 当前是一个以“时间排期 + 本地笔记 + 桌面快捷执行”为核心的 Windows 个人效率工作台，时间管理页负责组织今天，笔记页负责沉淀内容，快捷浮窗负责把执行动作带到桌面表层。
