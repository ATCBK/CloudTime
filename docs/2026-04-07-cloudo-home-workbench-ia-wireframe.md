# Cloudo 首页 / 主工作台信息架构与线框说明

更新时间：2026-04-07

## 1. 文档目标

本文档基于 [2026-04-07-cloudo-next-phase-product-structure.md](d:/Project_building/Clouddo1/CloudTime/docs/2026-04-07-cloudo-next-phase-product-structure.md)，进一步把 Cloudo 下一阶段的首页 / 主工作台拆成可设计、可实现的页面结构。

这份文档解决 4 件事：

1. 首页第一屏到底应该出现什么
2. 主工作台各区域的主次关系如何排
3. 哪些信息应该显性展示，哪些应该藏在后面
4. 线框级别上，页面应该如何组织

## 2. 首页的核心任务

首页不是普通 dashboard，也不是待办列表入口。

首页的任务只有一个：

**让用户一打开就知道自己现在在推进什么。**

这件事比“展示更多信息”更重要。

因此首页必须优先回答这 4 个问题：

1. 我当前阶段的总主线是什么
2. 我当前主要在推进哪些领域
3. 我这周最重要的推进是什么
4. 我今天的真实时间安排如何承接这些主线

## 3. 首页信息架构

建议首页按 4 层组织。

### 3.1 顶层：当前阶段主线摘要

这是首页的视觉锚点。

它不是口号区，而是一个高度凝练的阶段状态层。

应该包含：

- 当前阶段名称
- 一句总主线摘要
- 当前周期范围
- 当前阶段整体推进状态
- 一个轻量主操作，例如“编辑本阶段”

作用：

- 帮用户建立方向感
- 让首页从一开始就区别于普通待办工具
- 给后续领域、本周、今天建立总上下文

### 3.2 第二层：重点领域

这是总主线向下展开的第一层。

建议显示 3 到 5 个重点领域，每个领域只展示少量核心信息：

- 领域名称
- 当前阶段主线
- 本周关注点
- 轻量进度状态

作用：

- 把抽象的阶段主线拆成可理解的推进方向
- 避免用户只看到一个空泛目标
- 让多领域并行推进这件事清楚但不复杂

### 3.3 第三层：本周主线

这是首页中最重要的执行收束层。

它应该比领域更具体，但比今天更抽象。

建议结构：

- 本周标题和周期
- 3 到 6 条本周主线
- 每条主线标注所属领域
- 每条主线显示推进状态和是否已落到今天

作用：

- 把阶段主线切成一周的可推进单元
- 避免用户从长期目标直接跳进今天细节
- 让今天的排程有明确服务对象

### 3.4 第四层：今日执行工作台

这是首页下半部分，也是现有 Time Manager 能力的升级版。

建议保留三栏思路，但重新定义角色：

- 左栏：今日待办池
- 中栏：真实时间画布
- 右栏：即时记录 / 轻笔记

新的要求是：

- 今日事项要能看出自己服务于哪条本周主线
- 待办池不应只是平铺列表，而要更像“待落入时间的执行单元”
- 右栏记录不能抢主工作区权重

## 4. 视觉与布局原则

### 4.1 视觉母题

首页采用黑白冷静型的桌面工作台方向：

- 黑白主导
- 极少量中性灰
- 克制的层级
- 安静的高对比
- 中等密度、秩序清楚

视觉上追求：

- 无感
- 高级
- 硬朗
- 安静
- 一眼可读

### 4.2 浅色 / 深色主题

首页必须从一开始就支持浅色和深色两套主题。

要求不是简单反色，而是两种模式都保持：

- 清晰的主次关系
- 稳定的可读性
- 高级感
- 同样的“主线一眼可见”

### 4.3 信息密度

首页不走极度留白，也不做高密度控制台。

建议采用中等密度：

- 第一屏可以看清阶段主线、领域和本周主线
- 今日执行区域进入第二屏或第一屏下半段
- 同屏既有方向，也有实际操作入口

## 5. 线框结构

以下为建议线框。

## 5.1 页面总体框架

```text
+--------------------------------------------------------------+
| 左侧导航栏                                                   |
| 品牌 / 主工作台 / 笔记 / 信息池 / 设置 / 主题切换 / 浮窗     |
+----------------------+---------------------------------------+
|                      | 顶层：当前阶段主线摘要               |
|                      | 阶段名 / 总主线 / 周期 / 状态 / 操作  |
|                      +---------------------------------------+
|                      | 第二层：重点领域卡片                 |
|                      | 学习 / 输出 / 项目 / 健康 ...        |
|                      +---------------------------------------+
|                      | 第三层：本周主线                     |
|                      | 本周最重要的 3-6 条推进项           |
|                      +---------------------------------------+
|                      | 第四层：今日执行工作台               |
|                      | 左：待办池 中：时间画布 右：轻笔记   |
+----------------------+---------------------------------------+
```

## 5.2 顶层主线摘要线框

```text
+--------------------------------------------------------------+
| 当前阶段 · 2026 春季学期                                     |
| 建立稳定输出节奏，把考研学习、产品设计和身体状态同时带起来   |
| 16 周周期 | 第 7 周 | 总体推进稳定                           |
| [查看阶段] [编辑阶段]                              Theme ○● |
+--------------------------------------------------------------+
```

设计要求：

- 不是 hero 大图
- 更像高端工作台的“总状态条”
- 文字简练，层级明确

## 5.3 重点领域线框

```text
+----------------+  +----------------+  +----------------+  +----------------+
| 学习           |  | 输出           |  | 项目           |  | 健康           |
| 数学一轮推进   |  | 每周一篇沉淀   |  | 新首页重构     |  | 建立稳定作息   |
| 本周：极限专题 |  | 本周：写结构稿 |  | 本周：线框确认 |  | 本周：4次运动  |
| 稳定推进       |  | 稍慢           |  | 关键周         |  | 回到轨道       |
+----------------+  +----------------+  +----------------+  +----------------+
```

设计要求：

- 卡片信息不能太多
- 更像方向锚点，不是小 dashboard
- 当前阶段主线和本周关注点要同时可见

## 5.4 本周主线线框

```text
+--------------------------------------------------------------+
| 本周主线                                                     |
| 04.07 - 04.13                                               |
|                                                              |
| [学习] 完成极限专题第一轮整理                   70%          |
| [项目] 确认 Cloudo 新首页信息架构               40%          |
| [输出] 完成一篇结构化产品文档                   未开始       |
| [健康] 连续四天 23:30 前休息                    2 / 4        |
+--------------------------------------------------------------+
```

设计要求：

- 比领域更具体
- 比任务更抽象
- 一眼能看出这周到底在推进什么

## 5.5 今日执行工作台线框

```text
+----------------------+-----------------------------+----------------------+
| 待落入今天           | 今天 · 4 月 7 日            | 即时记录             |
|                      |                             |                      |
| [学习] 导数题组 A    | 08:00 数学专题整理         | 今天执行里发现的点   |
| [项目] 首页线框梳理  | 10:30 首页主线区设计       | 先记这里，不打断流   |
| [输出] 写文档段落    | 14:00 文档初稿             |                      |
| [健康] 晚间快走      | 20:30 晚间运动             |                      |
|                      |                             |                      |
| + 新建任务           | 时间轴支持拖拽、调整、完成 | 支持最轻量编辑       |
+----------------------+-----------------------------+----------------------+
```

设计要求：

- 中栏依旧是执行核心
- 左栏和中栏关系比右栏更强
- 事项与本周主线的关联要可见

## 6. 导航建议

建议下一阶段侧边导航按以下逻辑组织：

- 品牌 / 首页
- 主工作台
- 笔记
- 信息池
- 设置

高频辅助操作：

- 主题切换
- 快捷浮窗
- 快速新建

导航视觉建议：

- 极简图标
- 小面积高对比 hover
- 不做多余装饰
- 选中态稳定、克制

## 7. 哪些东西不应出现在首页第一版

为了保持无感和高级感，首页第一版不建议直接放入：

- 长篇说明文案
- 复杂成长成就中心
- 大量图表
- 沉重统计分析
- 信息池的完整列表
- 过多操作按钮

首页应先保证“方向感 + 本周收束 + 今日执行”三件事成立。

## 8. 本版原型验证重点

首页原型最值得验证的是：

1. 总主线摘要是否足够有锚点感
2. 领域卡片是否既清楚又不显复杂
3. 本周主线是否真的起到承上启下作用
4. 今日执行区是否仍然保持原有时间管理强项
5. 整体是否符合“无感但高级”的目标

## 9. 一句话总结

Cloudo 新首页不该像普通 dashboard，也不该像功能入口页，而应该像一个安静、高级、克制的个人主线控制台，让用户一打开就知道自己当前阶段在推进什么，并且顺着本周主线自然落到今天的真实时间安排中。
