# Time Manager Todo Type Filter + Modal Create Design

**Date:** 2026-02-27
**Status:** Approved
**Owner:** Codex + User

---

## 1. Goal

在时间管理页完成待办池分类能力升级与创建入口改造：
1. 待办池内提供“类型分类查看”能力，支持自定义类型、左右箭头切换、超长横向滚动。
2. 新建待办改为弹窗创建；弹窗内通过下拉框选择类型。
3. 默认类型为“通用”，历史空类型任务自动归并到“通用”。

## 2. Scope

### In Scope

- 左侧待办池增加类型分类条（可滚动 + 左右切换）。
- 待办列表按当前类型筛选，规则为“仅显示当前类型任务”。
- 分类条右侧提供“+ 新类型”入口，支持就地创建类型。
- 新建任务入口改为弹窗；创建表单中的“项目”升级为“类型”下拉选择。
- 继续复用 `TodoItem.project` 作为类型存储字段（仅语义和文案升级）。
- 默认类型固定为“通用”。

### Out of Scope

- 不做类型重命名、删除、拖拽排序。
- 不修改时间轴拖拽、日/周/月视图核心逻辑。
- 不调整存储结构为新字段（不新增 `TodoItem.type`）。

## 3. UX Decisions

### Todo Pool 分类条

- 布局：`[◀] [类型标签滚动区] [▶] [+ 新类型]`。
- 选中态清晰可见，切换后列表立即过滤。
- 类型过多时标签区保持单行横向滚动，不换行。
- 左右箭头支持快速切换当前类型，并驱动滚动区跟随。

### 新建待办弹窗

- 点击“+ 新建任务”打开弹窗。
- 表单字段：标题、时长、详情、类型（下拉框）。
- 下拉选项来源于类型列表；默认选中当前筛选类型，若无则“通用”。
- 关闭策略：取消按钮/遮罩关闭；提交成功后关闭并清空临时输入。

### 新类型创建

- 点击“+ 新类型”在分类条区域就地展开输入框。
- 新类型创建成功后自动选中新类型，并按该类型过滤显示。

## 4. Architecture & Data Flow

1. 新增类型存储：`cloudo.time.todoTypes`（`string[]`）。
2. 初始化类型列表：
   - 固定包含“通用”；
   - 合并 `todosState` 中现有 `project` 值（去重、trim）；
   - 空值统一映射为“通用”。
3. 新增当前筛选状态：`selectedTodoType`。
4. 待办池渲染时按 `todo.project`（空值按“通用”）与 `selectedTodoType` 匹配过滤。
5. 新建待办提交时将下拉选中类型写入 `project`。

## 5. Validation Rules

- 新类型名称：`trim()` 后不能为空。
- 新类型最大长度限制（建议 20）。
- 类型去重：大小写与前后空格归一后判重。
- 历史空值类型任务统一展示为“通用”。

## 6. Error Handling

- 新类型重复时提示并阻止创建。
- 新类型为空时提示并阻止创建。
- 当前类型下无任务时显示空态文案（不自动切换类型）。

## 7. Test & Acceptance

### Functional Acceptance

1. 待办池分类条可左右滚动，箭头可切换类型。
2. 切换类型后，列表仅显示该类型任务。
3. “+ 新类型”可创建新类型，创建后自动选中并生效过滤。
4. 新建任务弹窗可通过下拉框选类型，提交后任务出现在对应分类。
5. 旧数据空类型任务显示在“通用”分类。

### Automated Test Target

- 类型列表初始化与归并逻辑（含“通用”注入）。
- 类型筛选逻辑（仅显示当前类型）。
- 新类型校验（空值/重复/成功）。
- 新建任务时类型写入 `project`。

## 8. Risks

- `styles.css` 规则较多，新增分类条和弹窗样式可能被历史选择器覆盖。
- 本次继续复用 `project` 字段，后续若扩展“项目 + 类型”双维度需要一次模型升级。

## 9. Rollout Plan

1. 先实现类型状态与筛选逻辑（含兼容映射“通用”）。
2. 再完成待办池分类条与新类型创建交互。
3. 最后替换新建入口为弹窗 + 类型下拉，并补齐测试。
